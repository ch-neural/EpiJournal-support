支援與聯絡

需要協助、想回報問題或提出建議？請用下列任一方式聯絡我們。我們通常會在 3–5 個工作天內回覆。

客服聯絡方式

Email
support@ch-neural.com
（若你希望更換 Email，請直接修改此頁面）
問題追蹤（建議）
GitHub Issues
可附上截圖/錄影與版本資訊，方便我們追查。

回報問題時請提供

  • 你遇到的狀況（期待結果 vs 實際結果）
  • 重現步驟（Step-by-step）
  • App 版本（例如 1.0.0）、裝置型號、iOS 版本
  • 相關截圖/錄影（可遮住個資）

常見問題（FAQ）

Q App 有閃退/卡住怎麼辦？

  • 先嘗試重新啟動 App，或重新開機。
  • 確認你已更新到最新版本。
  • 若問題仍在，請依上方「回報問題時請提供」寄送資訊。

Q 我想提出新功能/改進建議。

  • 請到 GitHub Issues 建立一則 Feature Request。
  • 請描述你的使用情境與「為什麼需要」，我們會更容易評估優先順序。

Q 我想申請資料匯出/刪除（若適用）。

  • 請寄信到 support@ch-neural.com，主旨請包含「EpiJournal 資料匯出/刪除」。
  • 為了避免誤刪，我們可能會請你提供必要的驗證資訊（依實際功能而定）。
  • 更多細節請見 Privacy Policy。
