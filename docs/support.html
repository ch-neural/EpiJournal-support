Support & Contact

Need help, want to report a bug, or have a feature request? Contact us using one of the options below. We typically respond within 3–5 business days.

Contact

Issue tracker (recommended)
GitHub Issues
Include screenshots/videos and version info to help us investigate.

When reporting an issue, include

  • What you expected vs what happened
  • Steps to reproduce
  • App version (e.g., 1.0.0), device model, iOS version
  • Screenshots or screen recordings (please redact sensitive info)

FAQ

Q The app crashes or freezes. What should I do?

  • Try force-closing and reopening the app, or restarting your device.
  • Make sure you're on the latest version.
  • If the issue persists, send us the details listed above.

Q I have a feature request or improvement idea.

  • Create a feature request at GitHub Issues.
  • Please include your use case and why it matters—this helps us prioritize.

Q I want to request data export or deletion (if applicable).

  • Create a new request at GitHub Issues with a title like “Privacy request: Data export/deletion”.
  • Please do not include sensitive personal information in a public issue. Share only what is necessary to identify the request.
  • To prevent accidental deletion, we may ask for verification details (depending on the features in use).
  • See Privacy Policy for more information.

Privacy-related requests

If you want to access, export, or delete your data (where applicable), submit a request via GitHub Issues. Please do not post sensitive personal data publicly.
